CI/CD за 30 минут

Настраиваем GitHub Actions для автоматического деплоя на GitHub Pages.

Зачем это нужно

Ручной деплой — это лишние шаги, забытые файлы и «а у меня локально работало». CI/CD автоматизирует публикацию: запушили в `main` — сайт обновился.

Шаг 1. Включите GitHub Pages

В настройках репозитория → Pages → Source: GitHub Actions.

Шаг 2. Создайте workflow

Файл .github/workflows/deploy.yml:

name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v4
      - uses: actions/upload-pages-artifact@v3
        with:
          path: .
      - uses: actions/deploy-pages@v4

Шаг 3. Запушьте

git add .
git commit -m "Add GitHub Actions deploy"
git push

Шаг 4. Проверьте

Вкладка Actions в репозитории — workflow должен пройти зелёным. Сайт обновится автоматически.

Итог

Теперь каждый `git push` в `main` публикует сайт. Никаких ручных операций.
